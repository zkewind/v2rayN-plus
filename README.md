# v2rayN-plus

基于 [2dust/v2rayN](https://github.com/2dust/v2rayN) 的增强分支，当前在源项目基础上重点补充了这些能力：

- 新增“当前连接”“进程连接”标签页，便于直接查看运行时连接与进程映射关系
- 进程连接视图支持显示出站信息、按进程组整理，并可从进程/进程组快速生成路由规则
- 新增“路由规则”标签页，提升路由规则的浏览、定位与编辑效率
- Avalonia 桌面端导航调整为顶部标签页，常用页面切换更直观

这是一个适用于 Windows、Linux 和 macOS 的图形界面客户端，支持 [Xray](https://github.com/XTLS/Xray-core)、[sing-box](https://github.com/SagerNet/sing-box) 以及[其他内核](https://github.com/2dust/v2rayN/wiki/List-of-supported-cores)。
